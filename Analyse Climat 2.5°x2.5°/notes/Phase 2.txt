Phase 2 — Extraction des 18 variables climatiques GRIB2 (état final)

  A. Objectif

  Produire le CSV monthly_global_means_25.csv contenant pour chaque mois de 1979-01 à 2025-12 les moyennes globales pondérées cos(lat) des 18 variables, prêt à fusionner avec co2_mm_gl.csv pour les phases 3 (robustesse) et 4 (corrélations climat ↔ CO2).

  C. Pipeline en 4 étapes (état final)

  Le pipeline a évolué : on insère désormais un dossier subset GRIB intermédiaire (étape 0) qui rend le reste du pipeline 5× plus rapide et 20× plus léger sans aucune perte d'information.

  Étape 0 — Extraction GRIB miroir (15_extract_grib_subset.sh)

  Pour chaque fichier mensuel de la source, wgrib2 -match -grib_out filtre les 18 records utiles puis les écrit dans un nouveau GRIB2 miroir.

  Source : Data/2.5° x 2.5°/YYYY/pgbl04.gdas.YYYYMM.{grb2,grib2}
  Sortie : Final Version/2.5° x 2.5° subset/YYYY/pgbl04.gdas.YYYYMM.{grb2,grib2}

  ┌───────────────────────────────────┬───────────────────────────────┐
  │             Métrique              │          Valeur final         │
  ├───────────────────────────────────┼───────────────────────────────┤
  │ Records par fichier subset        │ 18                            │
  ├───────────────────────────────────┼───────────────────────────────┤
  │ Taille moyenne par fichier subset │ ~310 Ko                       │
  ├───────────────────────────────────┼───────────────────────────────┤
  │ Volume total subset               │ 172 Mo (vs 3.5 Go source)     │
  ├───────────────────────────────────┼───────────────────────────────┤
  │ Durée                             │ 1 min                         │

  │ Conservation                      │ bytes GRIB verbatim (lossless)│
  └───────────────────────────────────┴───────────────────────────────┘

  Pattern de filtrage en 3 groupes :
    1. Variables simples avec niveau "propre" (TMP@2m, TMP@500mb, SPFH@2m, APCP@surface, PRMSL@MSL, CSDSF/CSUSF/CSDLF/CSULF, CDUVB/DUVB/ALBDO@surface)
    2. DLWRF/ULWRF/USWRF/DSWRF@surface ancrés sur la fenêtre [0-9]+@4 hour pour absorber 32@4h (CFSR/CFSv2 < 2022) et 31@4h (CFSv2 ≥ 2022)
    3. PWAT/TCDC@entire atmosphere (espace en suffixe pour éviter les parenthèses)

  Étape 1 — Conversion GRIB → NetCDF (01_extract_subset.sh)

  Pour chaque mini-GRIB du subset, wgrib2 -set_date -set_ftime -netcdf harmonise les estampilles temporelles puis convertit en NetCDF.

  Source : Final Version/2.5° x 2.5° subset/YYYY/pgbl04.gdas.YYYYMM.{grb2,grib2}
  Sortie : Final Version/processed/nc_subset_25/YYYY/YYYYMM.nc

  │ Fichiers NetCDF       │ 564                         │
  ├───────────────────────┼─────────────────────────────┤

  │ Volume total          │ 413 Mo                      │
  ├───────────────────────┼─────────────────────────────┤
  │ Durée                 │ 16 sec                      │
  └───────────────────────┴─────────────────────────────┘

  Note : le set_date / set_ftime est nécessaire car certains fichiers récents (2022+) contiennent des records aux fenêtres de prévision différentes (0-4h vs 4-6h) que wgrib2 -netcdf rejette comme "input time before initial".

  Étape 2 — Moyennes globales pondérées cos(lat) (02_global_means.R)

  Pour chaque NetCDF :
  1. ncdf4::nc_open() lit le fichier (lib R sans dépendance GDAL — terra n'est pas installable sans gdal-config)
  2. Vecteur de poids cos(lat) calculé une seule fois (la grille 144 × 73 est constante)
  3. Pour chaque variable : weighted.mean(values, w_grid) avec gestion des NA
  4. Empilement dans un data.frame [year, month, date, T2m, T500, SPFH2m, PWAT, APCP, TCDC, DLWRF, ULWRF, DSWRF, USWRF, PRMSL, CSDSF, CSUSF, CSDLF, CSULF, CDUVB, DUVB, ALBDO]

  Sortie : outputs/monthly_global_means_25.csv (564 lignes × 21 colonnes).
  Durée  : 10 min 8 sec.

  Calcul des Cloud Radiative Effects :
  - CRE_SW  = (DSWRF − USWRF) − (CSDSF − CSUSF)   →  −45.1 W/m² (refroidissement par les nuages)
  - CRE_LW  = (DLWRF − ULWRF) − (CSDLF − CSULF)   →  +25.4 W/m² (réchauffement par les nuages)
  - CRE_net = CRE_SW + CRE_LW                     →  −19.7 W/m² (≈ consensus IPCC −20 W/m²) ✓

  Étape 4 — Fusion avec le CO2 (04_merge_with_co2.R)

  Fusion sur (year, month) avec co2_mm_gl.csv → tableau master climate_co2_monthly.csv qui sert d'entrée à toutes les analyses de phase 3 (robustesse) et phase 4 (corrélations).

  Désaisonnement et détendrage sont effectués au niveau du script 05_preparation.R (5 représentations level/anom/resid/d1/d12).
