Phase 4 — Lien climat ↔ CO2

  A. Objectif

  Étudier la relation statistique entre les 18 variables climatiques globales (+ 3 CRE dérivés) et la concentration atmosphérique mondiale de CO2 (NOAA GML, série co2_trend désaisonnée).

  Trois questions guident l'analyse :

  1. La trajectoire du CO2 et celle des variables climatiques sont-elles statistiquement liées AU-DELÀ de leur tendance commune ?
  2. Si oui, quelles variables expliquent le mieux la variance INTERANNUELLE du CO2 ?
  3. Le sens du lien est-il climat → CO2 (carbon cycle response) ou CO2 → climat (forçage radiatif direct) à l'échelle de quelques mois à quelques années ?

  Note : la phase 4 utilise les données après homogénéisation CFSR/CFSv2 (phase 3). Sur les niveaux bruts, les corrélations sont fallacieusement amplifiées par le saut technique de jan 2011.

  B. Préparation : 5 représentations temporelles (05_preparation.R)

  Les niveaux bruts du climat et du CO2 partagent tous deux une tendance long-terme. Une corrélation calculée sur les niveaux bruts est dominée par cette tendance commune et ne dit rien sur le lien interannuel propre. On construit donc 5 représentations :

  ┌──────────┬───────────────────────────────┬────────────────────────────────────────────────────────────┐
  │ Repr.    │ Formule                       │ Capture                                                    │
  ├──────────┼───────────────────────────────┼────────────────────────────────────────────────────────────┤
  │ level    │ X_t                           │ tendance + saison + interannuel + bruit                    │
  │ anom     │ X_t − climatologie(month_t)   │ tendance + interannuel + bruit (saison retirée)            │
  │ resid    │ anom_t − fit_lin(t)           │ interannuel + bruit (KEY pour lien propre)                 │
  │ d1       │ X_t − X_{t−1}                 │ saisonnalité + bruit blanc                                 │
  │ d12      │ X_t − X_{t−12}                │ taux d'évolution interannuel                               │
  └──────────┴───────────────────────────────┴────────────────────────────────────────────────────────────┘

  Sortie : outputs/series_transformed.rds (liste de 5 dataframes 564 × 26)
  Aussi  : series_level.csv, series_anom.csv, series_resid.csv, series_d1.csv, series_d12.csv

  D. Matrice de corrélation sur résidus (heatmap)

  Plot : plots/06a_corr_heatmap.png

  Trois blocs apparaissent :
  - Variables radiatives all-sky très intercorrélées (DLWRF/ULWRF, DSWRF/USWRF) → multicolinéarité forte qui justifie le lasso.
  - Variables clear-sky très intercorrélées entre elles mais peu liées aux all-sky (les nuages dominent l'écart).
  - Le CO2 se corrèle modérément avec PWAT, T2m, T500, CRE_LW. Aucune corrélation > 0.6 sur résidus → pas de variable miracle qui expliquerait à elle seule la variance interannuelle.

  E. Régression multivariée (07_regressions.R)

  Trois approches en parallèle, toutes sur les résidus.

  E.1 Régression complète

  lm(co2_trend_resid ~ T2m + T500 + ... + CRE_net) avec les 21 prédicteurs.

  - Version brute       : R² = 0.750
  - Version homogénéisée : R² = 0.443

  E.2 Sélection stepwise AIC (backward)

  step(fit_full, direction = "backward") sur la version brute.

  - R² = 0.748 avec 12 variables retenues : T500, PWAT, APCP, TCDC, DSWRF, USWRF, PRMSL, CSUSF, CSDLF, CSULF, DUVB, ALBDO
  - Plot du fit : plots/07b_stepwise_fit.png — observé / prédit superposés
  - Plot des résidus : plots/07c_stepwise_residuals.png — léger pattern en U (limite du détendrage linéaire)

  E.3 Lasso avec validation croisée 10-fold (glmnet)

  - lambda.min = 0.0038 (sélectionné par CV)
  - 18 variables non nulles à lambda.min
  - Variables qui entrent en premier dans le chemin (les plus importantes) : T500, CSDLF, CSUSF, T2m, CSDSF
  - Plot : plots/07a_lasso_path.png — coefficients standardisés (β × sd(X)) pour permettre la comparaison entre variables de natures dimensionnelles différentes

  F. Tests de causalité de Granger (08_granger.R)

  Pour chaque variable X :
  - H0 (X ↛ CO2) : X ne cause pas CO2 au sens de Granger
  - H0 (CO2 ↛ X) : CO2 ne cause pas X au sens de Granger

  Lag fixé à 6 mois (motivé par la phase 1 : corrélation taux annuel CO2 ↔ ENSO peak à lag 6).

  Test sur deux représentations :

  ┌──────────────┬───────────────────────────────────────┬──────────────────────────────────────────┐
  │ Représent.   │ Granger X → CO2 significatif (p<0.05) │ Granger CO2 → X significatif             │
  ├──────────────┼───────────────────────────────────────┼──────────────────────────────────────────┤
  │ resid        │ 0 / 21 vars (signal trop bruité)      │ 0 / 21                                   │
  │ d12 (taux)   │ 15 / 21 vars                          │ 8 / 21                                   │
  └──────────────┴───────────────────────────────────────┴──────────────────────────────────────────┘

  Top 5 Granger X → CO2 sur d12 (les plus significatifs) :

  ┌──────────┬──────────────┐
  │ Variable │ p-value      │
  ├──────────┼──────────────┤
  │ CSDLF    │ 3.00e−9      │
  │ SPFH2m   │ 6.49e−9      │
  │ PWAT     │ 1.00e−8      │
  │ DLWRF    │ 1.16e−8      │
  │ T500     │ 2.21e−8      │
  └──────────┴──────────────┘

  Ces 5 variables sont des prédicteurs très significatifs du taux annuel CO2 à 6 mois d'avance.

  Synthèse des sens du lien (sur d12) :

  ┌───────────────────────┬─────┐
  │ X → CO2 uniquement    │ 10  │
  │ CO2 → X uniquement    │ 3   │
  │ Bidirectionnel        │ 5   │
  │ Aucun                 │ 3   │
  └───────────────────────┴─────┘

  → Le sens DOMINANT à l'échelle interannuelle est CLIMAT → CO2 : à un délai de 6 mois, les variations de température, vapeur d'eau et flux radiatifs précèdent les variations du taux annuel CO2.

  Mécanisme : climat tropical → photosynthèse / respiration biosphère → flux net atmosphère.

  Cette signature est cohérente avec le résultat ENSO de la phase 1 (corrélation taux annuel CO2 ↔ ONI = +0.28 à lag 6 mois).

  H. Conclusions scientifiques majeures

  1. Tendance commune ≠ lien physique. 10 variables sur 21 affichent r > 0.5 sur les niveaux et r < 0.25 sur les résidus → corrélation TROMPEUSE. Le détendrage est obligatoire pour étudier le lien interannuel propre.

  2. R² multivarié = 0.75 sur résidus version brute, 0.44 après homogénéisation. Une partie substantielle du R² brut était un artefact du saut CFSR→CFSv2 (phase 3). La valeur réaliste est ~0.44, soit ~6 prédicteurs explicatifs équivalents. Le lien climat-CO2 reste multivarié et significatif, mais plus modeste qu'il ne paraît avant correction.

  3. Causalité dominante climat → CO2 à 6 mois. Sur les taux annuels (d12), 15 variables sur 21 causent significativement le CO2 (p souvent < 1e−7), contre seulement 8 dans le sens inverse. Le carbon cycle response (réponse de la biosphère et de l'océan aux variations climatiques) précède les variations du CO2 atmosphérique.

  4. Cohérence avec la phase 1. Le lag 6 mois confirme le résultat ENSO observé sur les taux annuels CO2 ↔ ONI dans la phase 1 (r = +0.28 à lag 6).

  5. Signaux climatiques propres robustes : T2m, T500, SPFH2m, PWAT, DLWRF, ULWRF, CSDLF, CSULF, APCP, TCDC. Ces variables conservent une corrélation cohérente après désaisonnement, détendrage et homogénéisation — elles portent un signal climatique réel vis-à-vis du CO2 atmosphérique.

  K. Limites et améliorations possibles

  - Le détendrage linéaire laisse une courbure cubique résiduelle qui pénalise le R² (visible en U dans le fit). Un GAM ou polynôme cubique sur le temps comme régresseur de contrôle améliorerait probablement le R².

  - Les moyennes globales sont aveugles aux signaux régionaux dominants (Amazonie, Indonésie, Sibérie). Une analyse à 0.5° × 0.5° par bandes de latitude révélerait probablement des corrélations supérieures sur les régions tropicales.

  - Les tests de Granger ont été menés à un lag fixe de 6 mois ; une analyse multi-lag (1, 3, 6, 12 mois) raffinerait l'identification du délai dominant pour chaque variable.

  - Le passage à 0.5° × 0.5° permettrait des analyses régionales et un découpage par bandes de latitude (boréale, tropicale, australe), ce qui correspondrait mieux à l'asymétrie hémisphérique observée en phase 1 (ratio MLO/SPO = 5.6×).

  - L'homogénéisation CFSR/CFSv2 suppose un saut instantané et constant ; une approche plus fine (interaction step × month, ou référence externe ERA5) pourrait améliorer la qualité du signal.
